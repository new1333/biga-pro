## 本章目标

理解货币政策和财政政策对股市流动性的影响、经济周期的四个阶段，以及信用周期对资产价格的传导机制。

## 流动性：市场的"水"

<InvestTerm id="liquidity" term="流动性" mode="tooltip" />

**流动性**有两个层次的含义：宏观上指资金在市场中获得和流转的便利程度（"钱多不多、好不好借"），微观上指资产的变现难度。

在股市分析中，流动性是推动行情的重要力量。一个直观的比喻是：**流动性是池子里的水，资产价格是水上的船**——水多的时船自然往上浮（估值扩张），水少了船就往下沉（估值收缩）。

流动性的来源：

- 央行通过货币政策向市场注入或回收资金
- 居民储蓄向股市的迁移（如基民购买基金）
- 外资流入或流出（如 <InvestTerm id="northbound-trading" term="北向资金" />）

## 货币政策与财政政策

<InvestTerm id="monetary-policy" term="货币政策" mode="tooltip" />

**货币政策**是中央银行通过利率、准备金、公开市场操作等工具调节货币和信用环境的政策。对股市影响最大的货币政策操作包括：

- **降息**（降低基准利率）：降低资金成本 → 鼓励投资和消费 → 利好股市估值
- **降准**（降低银行准备金率）：释放更多资金到市场中 → 增加流动性
- **公开市场操作**：央行日常的买卖操作来调节短期资金

<InvestTerm id="fiscal-policy" term="财政政策" mode="tooltip" />

**财政政策**是政府通过税收、支出和债务安排影响经济运行的政策。财政政策对行业的影响更具体：

- **扩大财政支出**（如基建投资、新能源补贴）→ 直接利好相关行业公司的订单和利润
- **减税降费**→ 企业和居民收入增加 → 消费和投资意愿提升
- **发行特别国债**→ 为重大项目融资 → 影响资金面的同时拉动相关产业链

货币政策和财政政策通常配合使用：经济低迷时"货币宽松 + 财政扩张"，经济过热时"货币收紧 + 财政收窄"。

## 经济周期：四阶段的循环

<InvestTerm id="business-cycle" term="经济周期" mode="tooltip" />

**经济周期**是经济活动在扩张、放缓、衰退和复苏之间波动的过程。理解和接受经济周期的存在，是宏观投资思维的起点。

经济周期通常分为四个阶段：

1. **扩张期**：GDP 加速增长、企业利润上升、就业良好 → 股市整体偏强
2. **放缓期**：增速见顶并开始回落 → 股市波动加大，板块出现分化
3. **衰退期**：经济收缩、企业利润下降、失业增加 → 股市承压，防御性板块相对抗跌
4. **复苏期**：经济触底回升、政策宽松、信心恢复 → 股市从底部反弹

<InvestTerm id="credit-cycle" term="信用周期" mode="tooltip" />

**信用周期**是经济中信用扩张和收缩交替出现的过程。它与经济周期紧密相关但有自己的节奏：

- **信用扩张期**：银行放贷积极、企业借钱成本低、市场资金充裕 → 推动资产价格上涨
- **信用收缩期**：银行收紧贷款、企业融资困难、违约风险上升 → 资产价格承压

信用周期对 A 股的影响尤其显著——每当信贷显著放松时，股市往往会有较好的表现。

## 常见误区

1. **"经济好股市就一定好"**：股市和经济的领先关系不同。股市通常领先经济 6-12 个月——当经济数据看起来最好时（GDP 增速见顶），股市可能已经提前反映了顶部；当经济数据最差时，股市可能已经触底反弹。股民常说"股市不是经济的晴雨表，而是经济的领先指标"。

2. **"央行降息就利好股市"**：不一定。如果市场已经把"降息"充分预期了（已经在价格中反映了），降息落地时反而可能是"利好出尽"。更重要的是看降息**幅度**和**力度**是否超预期。

3. **"经济周期可以精准预测"**：没有人能精准预测周期的顶部和底部。周期的存在是确定的，但每个周期的持续时间和幅度各不相同。对投资者来说，判断"现在大概在什么阶段"比"接下来什么时候转折"更有意义。

## 本章总结

- **流动性**是推动资产价格的宏观"水源"——水涨船高
- **货币政策**管利率和资金量，**财政政策**管政府支出和税收
- **经济周期**分扩张、放缓、衰退、复苏四阶段——股市通常领先经济 6-12 个月
- **信用周期**是经济的放大器——信用扩张助涨、信用收缩助跌
