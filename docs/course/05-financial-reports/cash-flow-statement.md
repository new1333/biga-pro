## 本章目标

理解现金流量表的三大板块（经营、投资、筹资）、经营性现金流的重要性、资本开支和自由现金流的概念，以及"利润不等于现金"这个核心原则。

## 现金是氧气

在上一章我们学习了 <InvestTerm id="net-profit" term="净利润" />——但净利润是一个会计数字，它不是银行账户里的真金白银。一家公司可以在利润表上显示盈利，但现金账户却快要枯竭；也可以利润表显示亏损，但账户上现金流充裕。

**现金是氧气**——公司没有利润可以撑一段时间，但没有现金立马窒息。这就是现金流量表存在的意义。

## 现金流量表：三管齐下

<InvestTerm id="cash-flow-statement" term="现金流量表" mode="tooltip" />

**现金流量表**是反映公司在一定期间经营、投资和筹资现金流入流出的报表。它把现金的变动分成三个来源，让你清楚知道"钱从哪来、花到哪去"。

### 经营现金流：赚钱的本事

<InvestTerm id="operating-cash-flow" term="经营现金流" mode="tooltip" />

**经营现金流**是公司经营活动产生的现金流量——卖产品收到的现金、付给供应商的现金、发工资的现金……这是公司**自己造血**的能力。

经营现金流是投资者最需要关注的现金流指标。判断标准很简单：

- 经营现金流长期为正且大于净利润 → 优质（赚的钱真的进账了）
- 经营现金流为正但远低于净利润 → 需要关注（利润中有大量只是"账面数字"）
- 经营现金流为负 → 公司在消耗现金维持日常经营

### 投资现金流：花钱买未来

投资活动产生的现金流反映公司在长期资产上的投入——买设备、建厂房、收购公司、投资理财等。

分析投资现金流时最值得关注的是**钱花在了哪里**：

- **资本开支（买设备、建厂房）**——这是在投资主业、扩大产能，通常对长期发展有利
- **对外收购（买公司）**——需要结合收购标的的质量和价格来判断，高溢价收购未来可能带来商誉减值
- **投资理财**——如果一家实业公司把大量资金用于购买理财产品和股票投资而非主业扩张，说明主业可能缺少增长机会，或者公司对主业信心不足

成长期公司通常投资现金流为负（在花钱扩张），成熟期公司可能投资现金流接近零或为正。但关键不是正负，而是**投入的效率和方向**——如果投入大量资金到与主业无关的项目中，即使"在投资"也不一定对股东有利。

### 筹资现金流：问谁要钱

筹资活动产生的现金流反映公司如何从外部获得资金——向银行借款、发行债券或股票、偿还债务、支付 <InvestTerm id="dividend" term="分红" /> 等。

筹资现金流的关键判断：

- **公司是靠借钱（借款增加）还是靠吸引新股东（增发股票）来融资？**——前者增加债务负担，后者稀释现有股东权益
- **公司在持续借钱（筹资净流入），同时经营现金流为负**——公司靠借债维持运转，这是最危险的财务信号之一
- **筹资现金流持续为负（在还钱或分红）且经营现金流充裕**——公司在用自己赚的钱偿还债务或回馈股东，这是财务健康的标志

## 资本开支与自由现金流

<InvestTerm id="capex" term="资本开支" mode="tooltip" />

**资本开支**（CAPEX）是公司用于购建长期资产的支出——比如买生产线、建工厂、购置办公楼。这是"公司为了维持或扩大经营规模必须花的钱"。

<InvestTerm id="free-cash-flow" term="自由现金流" mode="tooltip" />

**自由现金流**（FCF）是经营现金流扣除维持或扩大经营所需资本开支后的现金流。它回答了投资者最关心的问题：**公司赚到的现金扣除必要的资本投入之后，还剩多少可以自由支配？**

自由现金流的意义：

- 自由现金流为正且充裕 → 公司可以分红、回购股票、还债、或寻找新的投资机会
- 自由现金流为负 → 公司在"烧钱"维持运营或扩张，需要外部融资来填补缺口
- 长期自由现金流持续增长 → 最优质公司的共同特征

<BaseCallout type="tip" title="自由现金流与估值">
自由现金流是很多估值方法（如后续会学到的 DCF 估值模型）的基础输入变量。一家公司的价值，从根本上讲，等于它未来能产生的自由现金流的折现总和。
</BaseCallout>

## 常见误区

1. **"净利润高 = 公司现金充足"**：这是新手最容易犯的财报错误。客户赊账买了很多货（应收账款增加），利润表上收入确认了、利润增加了，但现金并没有进账。看利润的同时必须看经营现金流。

2. **"自由现金流为负 = 公司不好"**：成长期公司（尤其是重资产行业或研发密集型行业）需要持续的资本开支来扩张规模，FCF 为负在这个阶段是正常的。关键要看这些投入未来能否产生足够的回报。

3. **"现金流量表数字不会造假"**：现金流比利润更难操纵，但不是绝对无法操纵。比如公司可以在年底借钱来美化期末现金余额、或者将经营现金流转移分类到其他项目下。

## 本章总结

- **现金流量表**分三块：经营（造血）、投资（花钱买未来）、筹资（外部输血）
- **经营现金流**是最核心的现金指标——正且大于净利润，说明盈利质量扎实
- **资本开支**是维持或扩张必须花的长期投入
- **自由现金流** = 经营现金流 - 资本开支，是公司"剩余可支配现金"的衡量标准

这三张报表——资产负债表、利润表、现金流量表——合起来就是财报的"铁三角"。下一章我们将学习如何通过关键指标（如 EPS、ROE）来提炼这三张报表中的核心信息。
