## 本章目标

本章是整站学习的入口。你将了解本网站的组织方式、术语体系的使用规则、风险提示的意义，以及如何利用学习进度跟踪自己的进展。

## 网站设计理念

想象你刚搬到一个新城市，需要学会看地图、认路标、了解交通规则，才能安全高效地到达目的地。投资学习也是一样——在接触股票、市场、指标这些具体内容之前，先了解"怎么学"和"学的时候注意什么"，会让整个学习过程更顺畅。

本网站按照"从易到难、从概念到应用"的顺序组织内容。每一章只引入少量新概念（术语），并假设你已经掌握了前面章节的内容。如果你跳着看，可能会遇到尚未解释的术语，这时候可以回到前面的章节补课。

<BaseCallout type="tip" title="学习建议">
建议按顺序学习，不要跳章节。如果中途遇到不熟悉的术语，可以悬停在术语上查看解释。
</BaseCallout>

## 术语体系使用说明

投资领域有大量专业词汇：市盈率、K线、ETF、分红……对新手来说，每遇到一个新词都像在学一门外语。

为了降低阅读负担，本站采用了一套术语引用系统：

- **首次出现**：当一个术语在你当前阅读的章节中第一次出现时，会用自然语言完整解释它。你会看到一个带下划线的术语，鼠标悬停（或点击）即可查看定义。
- **再次出现**：同一个术语在后面章节出现时，不再重复解释，而是以组件形式引用。你仍然可以悬停查看定义，但正文不会被打断。

举个例子：在后面的章节中，你会看到类似 `<InvestTerm id="stock" term="股票" />` 这样的写法，它在页面上会渲染为可交互的术语标签，鼠标悬停就能看到解释。这样你不需要记住所有术语，系统会在你需要的时候提供帮助。

## 风险提示说明

投资永远伴随着风险。本站会频繁出现类似下面的风险提示卡片：

<InvestRiskNotice kind="general" level="medium" title="风险提示示例" compact="false" />

风险提示分为不同类型：

- **市场风险**：因市场整体波动导致资产价格变化的风险
- **流动性风险**：无法以合理价格及时买卖的风险
- **估值风险**：估值判断与实际价值偏离的风险
- **杠杆风险**：使用借贷或衍生品放大波动的风险

不同风险提示有不同的严重等级（低/中/高/严重），请认真阅读每一条。它们不是摆设，而是保护你投资安全的护栏。

<BaseCallout type="warning" title="重要声明">
本网站所有内容仅用于教育目的，不构成任何投资建议。文中案例、数据均为教学示意，不代表真实投资推荐。投资决策请基于自己的独立判断。
</BaseCallout>

## 内容边界说明

本站当前聚焦于 **A 股投资**，覆盖从零基础到能够独立分析、独立决策、独立复盘的完整闭环。网站中可能会提到港股、美股、加密货币、量化投资等相关概念，但只是建立术语认知和边界意识，不会在当前阶段深入展开这些模块的正文。

## 本章总结

- 本网站按循序渐进的方式组织，建议按顺序学习
- 术语首次出现时完整解释，再次出现时以交互组件引用，无需记忆
- 风险提示是投资学习的护栏，请认真对待每一条
- 学习进度在本地浏览器中保存，方便随时继续
